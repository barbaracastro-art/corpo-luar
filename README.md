# corpo-luar
App local android para acompanhamento pessoal de ciclo menstrual a partir das lunações. 
Acesse no celular que ele salva os dados locais no seu celular. 
Sem uso dos seus dados. 
Inspirado no diagrama lunar da agenda Mandala Lunar, de Ieve Holthausen e Naíla Andrade (mandalalunar.com.br)
Desenvolvido com Claude.
